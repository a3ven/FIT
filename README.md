# Fit20 – تمرین در خانه

وب‌اپ استاتیک فارسی و راست‌چین برای برنامه تمرینی چهار هفته‌ای مبتدی، بدون نیاز به سرور یا دیتابیس.

## اجرا
فایل `index.html` را با مرورگر باز کنید. پیشرفت جلسات با `localStorage` در همان مرورگر ذخیره می‌شود.

## انتشار روی GitHub Pages
1. یک repository جدید در GitHub بسازید.
2. فایل `index.html` را در ریشه repository آپلود کنید.
3. از مسیر **Settings → Pages**، گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه `main` و پوشه `/ (root)` را انتخاب و Save کنید.
5. پس از چند دقیقه، لینک سایت در همان صفحه Pages نمایش داده می‌شود.

این پروژه به build step، پکیج یا API نیاز ندارد.
